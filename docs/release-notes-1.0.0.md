**Mobile UI Checker 1.0.0**: find phone and tablet UI problems in Roblox Studio, in one click.

Checks every visible button and text for:
- 🔴 buttons that overlap (each other, or Roblox's thumbstick / jump button)
- 🟠 buttons too small for a thumb (44 px by default)
- 🟣 things off the screen
- 🔵 things under the notch / camera hole
- 🟢 things under Roblox's top-left buttons
- 🟡 text too small to read (12 px by default)

Results show as a clickable list (selects the item in Explorer) and as coloured boxes on screen. **WATCH** keeps scanning while you click through your menus.

## Install
1. Download **`MobileUIChecker.lua`** below.
2. Studio → **Plugins** tab → **Plugins Folder** → drop the file in.
3. Restart Studio → **Doom Studio** toolbar → **Mobile UI Check**.

Best used in **Play** with **Test → Device** (Device Emulator) set to a phone and a tablet.
